# Мировая база футболистов — версия 0.16.0

Источник: https://github.com/withqwerty/reep/blob/main/data/people.csv
Лицензия: CC0 1.0 (публичные данные, публичный реестр Reep v0).
Срез реестра заморожен на 21 июня 2026. В исходном CSV есть и тренеры,
поэтому скрипт оставляет только записи типа player. Годы рождения
по умолчанию 1981–2011; без даты рождения записи также учитываются.

Генератор: `python tools/build_world_database.py`.
Проверки: стабильные ID Reep, дедупликация ID и QID, корректные даты,
UTF-8, страна, позиция; создаётся мета-файл с точным числом записей.

ВАЖНО: реестр идентификаторов НЕ подтверждает клуб игрока или то, что он
продолжает выступать в ноябре 2026. Каталог — независимый справочник;
не участвует напрямую в симуляции трансферов. Навыки и ценники FIFA/FM
не импортируются. Игра продолжает использовать 72 игровые команды и
сохранённые карьерные данные старых версий.
