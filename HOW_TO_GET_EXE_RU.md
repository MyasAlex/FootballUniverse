# Как получить Windows EXE без установки C++

Компилятор на вашем компьютере не нужен. GitHub Actions бесплатно или в рамках доступного лимита может собрать Windows-игру на удалённом компьютере. Для этого требуется учётная запись GitHub и репозиторий с исходниками.

1. Зайдите на https://github.com и войдите в аккаунт.
2. Создайте новый репозиторий (например, `FootballUniverse`).
3. Загрузите **содержимое распакованного архива**, сохранив структуру папок, включая `.github/workflows/windows.yml`, `src`, `include`, `data`, `assets`, `tests`, `CMakeLists.txt`.
   ВНИМАНИЕ: `.github` — скрытая папка. Если загружаете через веб, убедитесь, что файл `.github/workflows/windows.yml` добавлен в репозиторий. При необходимости создайте его через веб-редактор GitHub (Add file > Create new file, имя `.github/workflows/windows.yml`) и скопируйте текст из архива.
4. Откройте вкладку **Actions**, выберите **Compile Windows game (no PC compiler required)** и нажмите **Run workflow**. Или используйте автоматически стартовавшую сборку после первого push.
5. Когда запуск завершится успешно, откройте его и внизу в **Artifacts** скачайте `FootballUniverse-Windows-EXE`.
6. Распакуйте скачанный архив, затем распакуйте находящийся в нём `FootballUniverse_Windows_x64.zip`.
7. Запустите `PLAY.bat` или `FootballUniverse.exe`.

Если Actions выдаст ошибку, пришлите текст из красного шага — поправим исходники или workflow.

Важно: это не уже собранная игра. В приложенном ZIP находится исходный проект и инструкция для удалённой сборки. Windows-сборка и интерфейс ещё не были протестированы в данной среде.
