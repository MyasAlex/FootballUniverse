Добавление гербов:
1. Сохраните логотип клуба как PNG (рекомендуется прозрачный фон, квадрат 256x256).
2. Назовите файл по id клуба из CLUB_IDS.csv: 0.png, 1.png и т.д.
3. Положите файл сюда и запустите build_windows.bat.
4. После сборки файлы копируются в build-windows/Release/assets/clubs.
Можно добавлять PNG напрямую в assets/clubs рядом с FootballUniverse.exe, без новой сборки.
Если файла нет, игра рисует временную круглую монограмму.
Для публикации с реальными гербами нужно проверить права использования.
