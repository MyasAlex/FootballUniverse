# Football Universe 0.4 — C++20, Windows, текстовый футбольный менеджер

**Статус: ранний, но играбельный прототип.** Развитие проекта 0.2, без Godot, Unity или Unreal.
Игровое ядро написано на C++20, оконный интерфейс на Win32. Не требуется интернет,
нейросетевые API или платный движок.

**Важно:** это ещё **не** полноценный Football Manager и не его код. Используется самостоятельная
реализация, а названия некоторых клубов служат демонстрационными данными. Реальные составы,
статистика и контракты 2026/27 **не включены**. Встроены 36 клубов в 6 мини-лигах, составы
процедурные. Результаты не претендуют на достоверность реальных соревнований.

## Обновление 0.4 — игровая механика

- «Состав» — назначайте капитана и вице-капитана, влияющих на команду.
- «Разговоры» — мотивационное собрание, похвала или критика всей команды (раз в 7 дней).
- «Трансферы» — скаутский отчёт после пяти игровых дней наблюдения, короткий список и фильтр избранных.
- Сохранения обновлены до FUSAVE_5 и читают файлы прежних версий 0.2/0.3.
- Windows-сборка в Actions проверяет открытие окна, а не только компиляцию.

## Дополнение 0.3.1 — эмблемы клубов

Оконная версия теперь показывает эмблему выбранного клуба при создании карьеры и в заголовке игры.
Логотипы не распространяются вместе с проектом: добавьте свои PNG в `assets/clubs/`.
Название каждого файла — числовой ID клуба: `0.png` для Арсенала, `1.png` для Ливерпуля и т.д.
Полный список находится в `assets/clubs/CLUB_IDS.csv`. Рекомендуемый размер PNG — 256 × 256, прозрачный фон.
При отсутствии файла отображается монограмма клуба. Сборка сама копирует папку с логотипами
к `.exe`. Также можно добавить PNG прямо рядом с собранной игрой в `assets/clubs` без перекомпиляции.
Для распространения реальных эмблем проверьте права на изображения.

## Что появилось в версии 0.3

1. **Стартовый состав (11 игроков)** у каждого клуба. Автовыбор по позициям и состоянию,
   один вратарь. Состав зависит от одной из пяти схем (4-3-3, 4-2-3-1, 4-4-2, 3-5-2, 5-3-2).
2. **Ручные изменения основы**: заменять выбранного игрока основы подходящим запасным.
   Учитываются позиции и травмы. Выбор основы **влияет на шансы в матче**.
3. **Ручные замены во время интерактивного матча**, до пяти замен. Нельзя повторно выпускать
   заменённого игрока или заменить вратаря полевым игроком.
4. **Индивидуальные тренировки**: отдельный фокус на один из десяти навыков для любого игрока,
   улучшение с учётом возраста и потенциала; влияние на физическое состояние.
5. **Более подробный матчевый движок**: комбинация с передачей и ударом, роль игрока при выборе
   бьющего, качество моментов, реальные футболисты своей текущей одиннадцатки, карточки,
   редкие травмы; тактика влияет на инициативу и частоту моментов.
6. **Исправлена статистика выходов на поле**: матч засчитывается только реально вышедшим
   футболистам, а не всем игрокам клуба. Запасные без выхода не получают матч в статистику.
7. **Формат сохранений FUSAVE_4**: составы, индивидуальная тренировка и ход замен сохраняются,
   в том числе посреди матча. Предыдущие сохранения **FUSAVE_3 от версии 0.2 читаются**,
   при загрузке автоматически выбирается стартовая одиннадцатка.
8. Дополнительные тесты новой логики и проверка загрузки старого сохранения.

## Запуск на Windows 10/11

1. Установите **Visual Studio 2022 Community** и компонент
   **Desktop development with C++ / Разработка классических приложений на C++**.
   Убедитесь, что доступен CMake.
2. Распакуйте архив `FootballUniverse_CPP_Windows_v0.3.zip`.
3. Запустите **`build_windows.bat`** двойным щелчком.
4. После успешной сборки откройте `build-windows/Release/FootballUniverse.exe`
   или запустите **`run_windows.bat`**.

Ручная сборка из Developer PowerShell:

```powershell
cmake -S . -B build-windows -G "Visual Studio 17 2022" -A x64
cmake --build build-windows --config Release
```

**В архиве исходники, а не готовый `.exe`.** Я проверил игровое ядро на Linux
с GCC, тестами и AddressSanitizer/UndefinedBehaviorSanitizer. Именно Windows Win32-сборку
в этой среде запустить и проверить не удалось; если сборка не пройдёт, нужен текст ошибки.

## Как играть в новые механики

**1. Стартовый состав:** «Состав» → выберите **запасного** слева → введите числовой ID
футболиста, который сейчас находится **в основе** (ID указан в списке и на панели информации)
→ нажмите «В основу». Подмена допускается только между близкими группами позиций:
вратари, защитники, полузащитники, атакующие. Кнопка «Автосостав» подбирает 11 автоматически.
Кнопка «Сменить схему» на странице «Тактика» автоматически подбирает состав под новую схему.

**2. Индивидуальные занятия:** «Тренировки» → выберите футболиста слева → нажимайте
«Фокус игрока», чтобы циклически выбирать навыки или вернуть «Командный план».
Кнопка «План команды» меняет общий режим занятий.

**3. Игра:** дождитесь дня матча на странице «Обзор», откройте «Матч» и нажмите «Начать матч».
Кнопка «+15 минут» продвигает время, «Сменить тактику» меняет установки, «2D / текст»
переключает схематичный вид. Для замены **выберите запасного слева**, в текстовое поле введите
ID игрока, который **сейчас на поле**, нажмите «Заменить». Если матч был мгновенно рассчитан,
во время него нельзя вмешиваться. Оба режима используют один подробный матчевый движок.

**4. Сохранения:** на странице «Обзор» нажмите «Сохранить» или «Загрузить».
Имя файла по умолчанию — `career.fus` **в текущей рабочей папке**.
При запуске `run_windows.bat` это `build-windows/Release/career.fus`.
Для переноса сохранения из 0.2 скопируйте свой старый `career.fus` в эту папку.
Система пока поддерживает один слот через интерфейс; сделайте резервную копию вручную.

## Прочие работающие прототипные возможности

- Роли: тренер, спортивный директор, владелец, президент, песочница; 4 пресета сложности.
- Выбор клуба и активных лиг; другие мини-лиги идут упрощённо.
- Игровой календарь; турнирные таблицы; бесконечная смена сезонов с регенами.
- 10 навыков по шкале 0–100, мораль, характер, доверие, семейные обстоятельства,
  травмы, потенциал, контракты, простые переговоры о переходах.
- Диалоги свободным текстом через **простую локальную систему намерений** (не LLM).
- Обращения к болельщикам, спонсоры, цены билетов, инвестиции, академия,
  почта и архив прошедших матчей.
- Импорт собственных футболистов из `data/players.csv`.

## Что ещё НЕ сделано

Полная база реальных футболистов 2026/27, сотни стран и низших лиг, лицензированные данные,
реальные календарные форматы соревнований, детальные роли футболистов и инструкции каждому,
тонкая модель замен и дисциплинарных дисквалификаций, полноценный VAR, международные турниры,
продвинутые агенты и контрактные пункты, долгосрочная память NPC, развитая личная жизнь,
ИИ-сотрудники, реальные сложные финансы, редактор лиг и работающий живой 2D-движок движения.
Условная 2D-схема — это визуальный макет поля, а не физическая анимация матча.
См. `docs/ROADMAP_RU.md`.

## Тесты ядра (Linux, macOS, Windows)

```shell
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build
ctest --test-dir build --output-on-failure
```

Проверяются базовая карьера, календарь, матчи, сохранение/загрузка, смена сезонов,
стартеры, корректность замен и их сохранения, индивидуальные тренировки и статистика.

## Правовые вопросы

Проект не связан с Sports Interactive. Реальные названия, логотипы, фотографии и коммерческие
базы данных игроков требуют проверки прав перед публичным коммерческим распространением.
