FOOTBALL UNIVERSE 0.14.1 — ИСХОДНИКИ

Исправлено:
1. Наложение текста после переключения вкладок и масштабирования окна.
2. Разделены игровые полномочия тренера, спортивного директора,
   владельца и президента. Песочница/свободная сложность сохраняет все права.
3. При трансляции матча владелец мяча и передачи связаны: нет
   независимых случайных перескоков с одной стороны поля на другую.
4. Текст и 2D-поле используют один источник игровых событий.
5. Сохраняется состояние владения мячом, новые карьеры — FUSAVE_14.
6. Старые карьеры 0.14 (FUSAVE_13) по-прежнему загружаются,
   включая карьеры с матчем в процессе.
7. Сохранены мировой рынок, расширенные фильтры, слоты сохранений.

ВНИМАНИЕ: не перезаписывайте старые сохранения до проверки!
Сделайте копии career.fus и папки saves.

Сборка:
- На Windows: build_windows.bat при установленном Visual Studio C++/CMake.
- Или загрузите исходники в GitHub, откройте Actions ->
  Compile Windows game (no PC compiler required) -> Run workflow.
  Готовая игра находится в артефакте FootballUniverse-Windows-EXE.

Проверки в Linux: 19/19 тестов пройдены.
Проверка запуска Windows GUI и геометрии окна запланирована в workflow.
